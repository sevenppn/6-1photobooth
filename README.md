# 📸 ระบบจัดเก็บค่าถ่ายรูป ม.6/1

ระบบจัดการแพ็กเกจถ่ายภาพและจัดเก็บค่าถ่ายรูปนักเรียนชั้นมัธยมศึกษาปีที่ 6/1 โรงเรียนสวรรค์อนันต์วิทยา พัฒนาด้วย Google Apps Script, Google Sheets และ HTML/CSS/JavaScript

ออกแบบมาเพื่อช่วยให้นักเรียนสามารถเลือกแพ็กเกจถ่ายภาพ ตรวจสอบยอดค่าใช้จ่าย และติดตามสถานะการชำระเงินได้ด้วยตนเอง พร้อมระบบสำหรับหัวหน้าห้องในการจัดการรายการสั่งซื้อ รับชำระเงิน และตรวจสอบภาพรวมทางการเงิน

---

## ✨ Features

### 👨‍🎓 Student System
- เข้าสู่ระบบด้วยรหัสประจำตัวนักเรียน
- เลือกแพ็กเกจรูปถ่ายรวมแบบมีกรอบหรือไม่มีกรอบ
- เลือกรายการเพิ่มเติมตามความต้องการ
- คำนวณยอดค่าใช้จ่ายอัตโนมัติ
- บันทึกและแก้ไขรายการก่อนชำระเงิน
- ตรวจสอบสถานะการชำระเงิน
- ดูรายละเอียดรายการของตนเอง

### 👨‍💼 Class Leader System
- เข้าสู่ระบบด้วยรหัสนักเรียนและ PIN
- ตรวจสอบรายการสั่งซื้อของนักเรียนทั้งห้อง
- ค้นหานักเรียนด้วยชื่อ รหัสนักเรียน หรือเลขที่
- กรองรายการตามสถานะการชำระเงิน
- บันทึกการรับชำระเงินสดและเงินโอน
- ยกเลิกสถานะการชำระเงิน
- ตรวจสอบภาพรวมการจัดเก็บเงิน
- ตรวจสอบยอดเงินที่หัวหน้าห้องแต่ละคนรับไว้

### ⚙️ Management System
- เปลี่ยนชื่อระบบ
- กำหนดราคาแพ็กเกจถ่ายภาพ
- กำหนดข้อความแจ้งวิธีชำระเงิน
- เปิดหรือปิดรับการเลือกแพ็กเกจ
- เพิ่ม แก้ไข และลบรายการเพิ่มเติม
- กำหนดประเภทรายการเป็นแบบบังคับหรือเลือกเอง
- เปลี่ยน PIN หัวหน้าห้อง

### 📊 Financial Dashboard
- จำนวนผู้เลือกแพ็กเกจ
- จำนวนผู้ชำระเงินแล้ว
- จำนวนผู้ยังไม่เลือกแพ็กเกจ
- ยอดเงินที่จัดเก็บได้
- ยอดเงินค้างชำระ
- แยกยอดรับเงินสดและเงินโอน
- แสดงยอดเงินแยกตามผู้รับเงิน
- สรุปจำนวนรายการถ่ายภาพที่ถูกเลือก

## 🚀 Installation

### 1. Create Google Sheets

1. สร้าง Google Spreadsheet ใหม่
2. เปิดเมนู **ส่วนขยาย (Extensions)**
3. เลือก **Apps Script**

### 2. Install Backend

1. เปิดไฟล์ `Code.gs`
2. นำโค้ด Backend จาก Repository ไปวาง
3. บันทึกโปรเจกต์

### 3. Install Frontend

1. กดปุ่ม `+` ในหน้า Apps Script
2. เลือก HTML
3. ตั้งชื่อไฟล์ว่า `Index`
4. นำโค้ดจาก `Index.html` ไปวาง
5. บันทึกโปรเจกต์

### 4. Initialize Database

1. เลือกฟังก์ชัน `setup`
2. กด Run
3. อนุญาตสิทธิ์การเข้าถึง Google Sheets
4. ระบบจะสร้างชีตและหัวตารางที่จำเป็นโดยอัตโนมัติ

**หมายเหตุ:** ฟังก์ชัน `setup()` สามารถเรียกใช้งานซ้ำได้ โดยไม่ลบข้อมูลเดิม แต่ควรตรวจสอบข้อมูลตัวอย่างและบัญชีเริ่มต้นก่อนเปิดใช้งานจริง

### 5. Configure Students

เพิ่มรายชื่อนักเรียนในชีต `Students`

| รหัสนักเรียน | ชื่อ-นามสกุล | เลขที่ | บทบาท | PIN |
|---|---|---|---|---|
| 10001 | ตัวอย่างหัวหน้าห้อง | 1 | leader | 1234 |
| 10002 | ตัวอย่างนักเรียน | 2 | student | |

- `leader` = หัวหน้าห้อง
- `student` = นักเรียนทั่วไป
- PIN ใช้เฉพาะบัญชีหัวหน้าห้อง

ให้เปลี่ยน PIN ตัวอย่างและลบข้อมูลนักเรียนตัวอย่างก่อนเปิดใช้งานจริง

### 6. Deploy Web Application

1. เลือก **Deploy**
2. เลือก **New deployment**
3. เลือกประเภท **Web app**
4. ตั้งค่า Execute as เป็น **Me**
5. กำหนด Who has access ตามกลุ่มผู้ใช้งานที่ต้องการและนโยบายของโรงเรียน
6. กด Deploy
7. คัดลอก Web App URL เพื่อเข้าใช้งาน

## 🗄️ Database Structure

ระบบใช้ Google Sheets เป็นฐานข้อมูลหลัก ประกอบด้วย 4 ชีต

### Students

เก็บข้อมูลนักเรียนและสิทธิ์การใช้งาน

| Column | Description |
|---|---|
| รหัสนักเรียน | Student ID |
| ชื่อ-นามสกุล | Student Name |
| เลขที่ | Class Number |
| บทบาท | User Role |
| PIN | Leader PIN |

### Orders

เก็บข้อมูลแพ็กเกจและการชำระเงิน

| Column | Description |
|---|---|
| รหัสนักเรียน | Student ID |
| แพ็คเกจรูปรวม | Selected Package |
| ยอดชำระ | Amount |
| สถานะ | Payment Status |
| เลือกเมื่อ | Order Date |
| ชำระเมื่อ | Payment Date |
| อนุมัติโดย | Approved By |
| รายการเพิ่มเติม | Additional Items |
| ช่องทางชำระ | Payment Method |

### Settings

เก็บการตั้งค่าระบบ เช่น ชื่อระบบ ราคาแพ็กเกจ และสถานะการเปิดรับรายการ

### Items

เก็บรายการเพิ่มเติม เช่น เสื้อห้องหรือพวงกุญแจ โดยแบ่งเป็น

- `required` — รายการบังคับสำหรับนักเรียนทุกคน
- `optional` — รายการที่นักเรียนสามารถเลือกเองได้

## 🔐 Security Notes

- ระบบใช้ Token สำหรับจัดการ Session
- Token มีอายุ 6 ชั่วโมง
- จำกัดการกรอก PIN ผิดของหัวหน้าห้อง 5 ครั้ง และระงับการลองใหม่ 10 นาที
- ตรวจสอบสิทธิ์หัวหน้าห้องในฟังก์ชัน Backend
- ใช้ LockService ป้องกันการทำงานพร้อมกันในบางกระบวนการที่แก้ไขข้อมูล
- ไม่ควรเผยแพร่ Google Sheets หรือข้อมูลนักเรียนเป็นสาธารณะ

**ข้อควรระวัง:** เวอร์ชันปัจจุบันยังเก็บ PIN เป็นข้อความธรรมดาใน Google Sheets และยังไม่มีระบบบันทึกประวัติการเปลี่ยนแปลงทางการเงินแบบแยกรายการ จึงควรปรับปรุงด้านความปลอดภัยและการตรวจสอบย้อนหลัง ก่อนนำไปใช้งานกับข้อมูลจริง
